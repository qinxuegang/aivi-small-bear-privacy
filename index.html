AIVI Small Bear Privacy Policy
AIVI 小熊隐私政策

Last updated / 最后更新：October 7, 2026 / 2026 年 10 月 7 日

AIVI Small Bear is a local Chrome extension for authorized AIVI Lab employees. Its single purpose is to collect employee-approved questions, AI answers, source links, and visible-page evidence from supported AI websites, preserve task progress locally, and export a standardized result package.

AIVI 小熊是供 AIVI Lab 授权员工使用的本地 Chrome 扩展。它的唯一用途是：按照员工确认的工作底稿，从受支持的 AI 网站采集问题、回答、来源链接和可见页面证据，在本机保存任务进度，并导出标准化结果包。

Data processed / 处理的数据

The extension processes only data needed for the employee-selected collection task:

  • workbook project and sample identifiers;
  • employee-approved question text;
  • AI answer text and source links shown on supported AI pages;
  • visible-page evidence images captured for the selected task;
  • task progress, queue, recovery, and sanitized diagnostic metadata; and
  • the URLs of supported AI conversation pages needed to continue or recover the selected task.

扩展仅处理员工所选采集任务需要的数据：工作底稿中的项目与样本标识、员工确认的问题文本、受支持 AI 页面显示的回答与来源链接、当前任务的可见页面证据图片、任务进度及恢复诊断信息，以及继续或恢复该任务所需的受支持 AI 对话网址。

The extension does not request or collect passwords, authentication cookies or tokens, payment or financial data, health data, precise location, general browsing history, contacts, advertising identifiers, or general keystroke activity.

扩展不会请求或收集密码、身份验证 Cookie 或令牌、支付或金融数据、健康数据、精确位置、一般浏览历史、联系人、广告标识符或一般键盘输入活动。

How data is used / 数据用途

The data is used only to perform the user-facing collection workflow: submit an approved question to the employee-selected AI service, read the displayed answer and sources, prevent duplicate submission, safely recover an interrupted submitted question, create visible-page evidence, and export the requested result package.

这些数据仅用于员工可见的采集流程：向员工选择的 AI 服务提交已确认问题、读取页面显示的回答和来源、防止重复提交、安全恢复中断但已提交的问题、生成可见页面证据，以及导出员工要求的结果包。

Storage, transfer, and sharing / 存储、传输与共享

Task state is stored locally in Chrome extension storage. Result workbooks, manifests, run logs, and evidence images are saved locally only when the employee requests an export. AIVI Small Bear has no application server and does not transmit collected workbook content, answers, evidence, or diagnostics to AIVI, an analytics provider, an advertising service, or a data broker.

任务状态保存在本机 Chrome 扩展存储中。结果工作簿、清单、运行日志和证据图片仅在员工要求导出时保存到本机。AIVI 小熊没有应用服务器，不会把工作底稿内容、回答、证据或诊断信息传输给 AIVI、分析服务、广告服务或数据经纪商。

When an employee starts a task, the approved question is sent over HTTPS to the selected supported AI website so that the site can produce an answer. Those sites process the prompt and display the answer under their own terms and privacy policies. This transfer is necessary for the extension's disclosed single purpose. The extension does not transfer user data for advertising, marketing, credit decisions, lending, or unrelated purposes.

员工开始任务时，已确认的问题会通过 HTTPS 发送到所选的受支持 AI 网站，以便该网站生成回答。这些网站依据各自的条款和隐私政策处理问题并显示回答。该传输是扩展已披露唯一用途所必需的。扩展不会为了广告、营销、信用判断、贷款或无关用途传输用户数据。

The extension does not sell user data. The developer does not permit humans to read user data unless the user explicitly asks for support involving specific data, access is necessary for security or legal compliance, or the data has been aggregated and anonymized for permitted internal operations. Employees control any later sharing of files they export.

扩展不会出售用户数据。除非用户明确要求针对特定数据提供支持、为安全或法律合规所必需，或者数据已汇总并匿名化用于允许的内部运营，否则开发者不会允许人员读取用户数据。员工自行控制其导出文件之后的共享行为。

Retention and deletion / 保留与删除

Local task state remains in the Chrome profile so an interrupted task can resume. It is replaced as the employee works with another task or removed when the employee clears extension data or removes the extension. Exported files remain on the employee's device until the employee deletes them using normal file controls.

本地任务状态保留在 Chrome 用户资料中，以便恢复中断任务；员工处理其他任务时它会被替换，也可通过清除扩展数据或移除扩展来删除。导出文件保留在员工设备上，直至员工使用常规文件管理方式删除。

Security and Limited Use / 安全与有限使用

The extension is packaged with all executable code and does not execute remotely hosted code. It uses only the Chrome permissions and official HTTPS origins listed in its manifest. Its use and transfer of information comply with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only when necessary for the extension's disclosed single purpose.

扩展随软件包提供全部可执行代码，不执行远程托管代码。它仅使用清单中列出的 Chrome 权限和官方 HTTPS 网站。扩展对信息的使用和传输遵守 Chrome 网上应用店用户数据政策（包括“有限使用”要求），并且仅在实现已披露唯一用途所必需时使用数据。

Contact / 联系方式

For access, deletion, security, or privacy questions, contact the AIVI Lab Development Owner or the administrator who provided the Chrome Web Store installation link.

如需咨询访问、删除、安全或隐私事项，请联系 AIVI Lab Development Owner 或提供 Chrome 网上应用店安装链接的管理员。
